# Approved references

One folder per character. Put approved images here named
`01-turnaround.png`, `02-expressions.png`, `03-hero-portrait.png`,
`04-phone-pose.png`, and fill in `NOTES.md`. A character is **locked** when
`01` and `03` are approved against the bible; film work uses only locked
characters. Images are large: commit them with Git LFS or keep them in shared
storage and record the link in `NOTES.md`.
