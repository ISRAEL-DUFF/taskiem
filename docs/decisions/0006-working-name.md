# 0006 — Working name Taskiem

Date: 2026-10-05 · Status: Accepted, pending trademark search

## Decision

The product's working name is **Taskiem**. Identifiers use lowercase `taskiem` (CLI binary, npm scope `@taskiem`, database roles, web component `<taskiem-builder>`).

## Open

Trademark search in Nigeria, and in Ghana and Kenya if targeted, is a Phase 0 task that needs a human and, ideally, counsel. If the name is not clear, identifiers are renamed before Phase 4 filing.

## Provenance

Chosen by the founder. It replaced an earlier working name, Taskier.
